# KKuTuIO Word Academy

## 목적

기존 단어장은 `시작 글자 + 선택 미션` 조건을 마스터 단어 DB에 직접 적용하고 결과를 한꺼번에 반환했습니다. 정상 이용자는 임의 지연을 감수해야 했지만, 자동 수집자는 시작 글자별 장문 집합을 복원할 수 있었습니다.

Word Academy는 다음 원칙으로 대체합니다.

1. **공개 학습 코퍼스와 마스터 DB를 분리합니다.**
2. **비어인정은 공개하고, 어인정은 관리자가 명시적으로 공개한 단어만 공개 코퍼스에 추가합니다.**
3. **비공개 어인정은 로그인, 단어 토큰, 계정·IP별 건수 제한을 통과한 소량 조회만 허용합니다.**
4. **검색·시뮬레이터·루트전·전략 분석·퀴즈는 같은 공개 코퍼스와 규칙 엔진을 사용합니다.**
5. **공개 코퍼스의 전체 다운로드나 범용 Open API는 제공하지 않습니다.** 동일 출처 웹 UI가 사용하는 JSON 요청은 크기와 빈도에 제한을 둡니다.

## 공개 범위

| 사전 프리셋 | 포함 범위 |
| --- | --- |
| `BASIC` | `flag == 0`인 기본 단어 |
| `STANDARD` | 어인정 비트가 없는 비어인정 단어 |
| `COMBINED` | `STANDARD` + 관리자가 명시적으로 공개한 어인정 |

어인정 공개 여부는 게임 판정용 `flag` 비트에 섞지 않고 `dictionary_public_word` allowlist에서 관리합니다. `hit` 값이나 등록 후 경과 시간에 따른 자동 공개는 하지 않습니다.

권장 운영 스키마는 다음과 같습니다. 애플리케이션도 기동 중 스키마를 확인해 생성할 수 있지만, 운영 DB 계정에 DDL 권한을 주지 않는 환경에서는 배포 전에 미리 적용하는 편이 좋습니다.

```sql
CREATE TABLE IF NOT EXISTS dictionary_public_word (
    lang VARCHAR(2) NOT NULL CHECK (lang IN ('ko', 'en')),
    word TEXT NOT NULL,
    reason VARCHAR(200) NOT NULL DEFAULT '관리자 공개',
    created_by VARCHAR(64) NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    PRIMARY KEY (lang, word)
);

CREATE INDEX IF NOT EXISTS idx_dictionary_public_word_created_at
    ON dictionary_public_word (created_at DESC);
```

이 테이블은 사용자 수와 무관하며, 명시적으로 공개한 어인정 수만큼만 증가합니다.

## 구성

### 공개 단어 사전

- 정확·포함·시작·끝 검색
- 시작 글자·끝 글자·미션 필터
- 길이·주제·속성 필터
- 사용 빈도·길이·가나다 정렬
- 단어 뜻, 주제, 다음 글자, 공개 코퍼스 기준 방어 단어 수
- 관리자 공개 어인정 표시

정확 조회도 공개 코퍼스만 조회합니다. 마스터 DB에만 있는 단어와 존재하지 않는 단어를 외부 응답으로 구분하지 않습니다.

### 수순 시뮬레이터

- 기초·표준·통합 공개 사전 선택
- 끝말잇기·앞말잇기
- 두음법칙
- 첫 단어와 URL 상태 공유
- 한 수씩 입력
- 중복·연결·공개 범위 판정
- 한 수 뒤로·초기화·수순 복사·공유
- 보호막
- 무작위·표준·고수 선택 봇
- 현재 수의 방어 수와 승패 상태
- 대안 수 추천

### 루트전 연습

- 입문·표준·실전 난이도
- 난이도별 시간 제한
- 첫 글자·길이·주제·예시 힌트
- 보호막
- 무작위 시작 음절 또는 지정 시작 음절
- 연속 봇 대국
- 대국 기록과 연속 성공 수
- 실패 시 공개 코퍼스 기준 좋은 수 표시

### 전략 엔진

- 음절별 `WIN`, `LOSS`, `ROUTE` 분류
- `n`수 이내 승리 음절
- 임계 단어
- 순환 루트의 강한 연결 요소 그룹
- 대표 전략 수순
- 제외 단어 적용
- 두 규칙·제외 목록의 상태 변화 비교
- 공개 분석 결과 JSON 내보내기

`WIN/LOSS` 계산은 현재 공개 코퍼스의 정적 유향 그래프에 대한 역행 분석입니다. 실제 게임에서 이미 사용된 단어의 영향을 반영하려면 제외 단어에 현재 체인을 전달합니다. 임의의 긴 no-repeat 게임 트리를 매 요청마다 완전 탐색하는 기능은 아니며, 이 차이를 UI에서 숨기지 않습니다.

### 오늘의 퀴즈

- 다음 글자
- 공개 사전 유효 단어
- 좋은 공격 수
- 날짜와 문제 번호에 따른 결정적 문제 생성
- 브라우저에 당일 점수와 연속 학습일 저장

퀴즈는 공개 코퍼스만 사용하며 비공개 어인정의 존재를 간접적으로 드러내지 않습니다.

### 게임 복기

기존 리플레이 상세 projection을 이용하며 새로운 계정×단어 테이블을 만들지 않습니다.

- 전역 성공 체인 `a`
- 플레이어별 분할 체인 `ap`
- 단어 dictionary `w`
- 입력 이벤트 `i`
- 플레이어 snapshot `p`
- 입력 시간, 성공·실패 표시
- 각 단어 뒤에 가능했던 공개 코퍼스 대안

복기는 기존 리플레이 공개·참가자 권한을 그대로 따르며 마스터 DB를 추가로 노출하지 않습니다.

### 비공개 어인정 제한 조회

- 통합계정 로그인 필수
- 시작 글자 조회: 단어 토큰 1개
- 미션 포함 조회: 단어 토큰 2개
- 계정당 일일 25회
- 동일 IP는 계정 한도의 3배
- 한 요청당 최대 20개
- 이미 공개된 어인정 제외
- Redis 장애 시 fail closed

공개 기능의 일반 rate limit은 Redis 장애 시 정상 이용 가능성을 위해 fail open하지만, 비공개 어인정 조회는 보안 상태를 저장할 수 없으면 차단합니다.

## 캐시와 성능

- 언어별 공개 기본 코퍼스: 최대 2개, 10분 TTL
- 규칙별 snapshot: 최대 24개, 5분 idle TTL
- 전략 그래프: 최대 12개, 8분 idle TTL
- 관리자 공개 변경 시 모든 관련 캐시 즉시 무효화
- 10분 주기 자동 갱신
- 검색은 페이지당 최대 100개
- 분석 제외 단어 최대 1,000개
- 전략 수순 깊이 최대 30

사용자별 발견 단어, bitmap, 영구 도감 데이터는 저장하지 않습니다. 메모리 사용량은 공개 코퍼스와 실제 사용 중인 소수 규칙 조합에 비례합니다.

## 관리자 API

`WORD` 권한과 통합계정 관리자 설정을 모두 확인합니다.

- `GET /api/admin/academy/public/{lang}`
- `PUT /api/admin/academy/public/{lang}/{word}`
- `POST /api/admin/academy/public/{lang}/bulk`
- `DELETE /api/admin/academy/public/{lang}/{word}`
- `POST /api/admin/academy/refresh`

비어인정은 이미 공개 코퍼스에 포함되므로 allowlist에 넣을 수 없습니다.

## 기존 경로 호환

- `/academy`: 정식 아카데미 경로
- `/wordsheet`: 같은 아카데미 화면을 제공하는 호환 경로
- `/dictionary/{lang}/{word}`: 공개 코퍼스의 정확 조회만 허용
- `/wordsheet/{lang}/{startChar}`: 기존 클라이언트를 위한 토큰 기반 비공개 어인정 제한 조회

기존 4~10초 임의 지연과 무제한 마스터 DB prefix 조회는 제거합니다.

CI에서 다음을 수행합니다.

```bash
pnpm verify
./gradlew check bootJar
```
